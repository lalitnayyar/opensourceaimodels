# Getting Started

## Installation

Install the dependencies and run the project:

```
npm install
npm start
```

## User Guide

To use the application, open your browser and navigate to `http://localhost:3000`. You can ask questions by appending the `?question=` parameter to the URL. For example:

```
http://localhost:3000/?question=What is the capital of France?
```

## Features

- **Express Server**: A simple Express server to handle HTTP requests.
- **Ollama Integration**: Uses the Ollama library to interact with the Mistral model.
- **HTML Response**: Formats the response in HTML for easy reading.

Head over to https://vitejs.dev/ to learn more about configuring vite.
